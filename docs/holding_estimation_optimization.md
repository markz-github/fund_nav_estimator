# 持仓法优化过程

更新时间：2026-08-10

## 1. 目标与边界

持仓法用于根据基金公开持仓和市场行情估算当日净值。它不是基金的实时完整持仓，也不能将模型推断表述为真实持仓。

优化目标：

- 真实反映公开持仓覆盖率；
- 在公开信息不足时，以可解释的代理收益估算未披露部分；
- 对 QDII 等存在跨市场时差和汇率影响的基金，按正确的交易日与币种口径估值；
- 使用严格的历史回测验证改动，而不是仅比较单日结果。

## 2. 已确认的问题

### 2.1 覆盖率被错误归一化

旧逻辑：

```text
coverage_ratio = 有有效行情的持仓权重 / 已披露持仓权重之和
```

季度报告通常只有前十大持仓。当全部前十大均有行情时，上式会得到 100%，即使前十大只占基金总资产的 60%。

新口径：

```text
coverage_ratio = 有有效行情且实际参与估值的持仓权重 / 基金总资产
```

基金总资产按 100% 作为分母。该字段表示“实时估值持仓覆盖率”，不再表示“已披露持仓中的行情完整度”。

历史估算与任务明细已按对应报告期的披露权重回填。例：022365 的 2026Q2 前十大权重合计为 61.88%，最新估算覆盖率应显示为 61.88%，而不是 100%。

建议长期保留两个不同字段：

- `disclosed_holding_coverage`：公开披露持仓权重总和；
- `quote_coverage`：公开持仓中拥有可用行情、实际进入估算的权重；

用户页面应优先展示前者或两者的组合，避免把行情完整度误认为资产完整度。

### 2.2 仅凭前十大无法精确估算主动基金

前十大之外的股票、债券、现金、基金份额和衍生品通常不可从季报逐只获得。基金经理也可能在报告期后调仓。因此，不能将前十大权重归一化到 100%，也不应根据上期持仓虚构本期仍持有的个股。

## 3. 公开信息的补充渠道

按披露完整度从高到低使用：

1. **基金公司定期报告与监管披露**：季报通常包含资产配置、行业配置、前十大股票和前五债券；中报、年报通常可获取更完整的证券组合明细，可据此统计股票和债券数量。
2. **基金公司产品页**：优先作为基金合同、业绩比较基准和正式报告的来源。
3. **数据聚合平台**：如天天基金的资产配置、股票持仓与债券持仓页面，适合作为抓取便利性补充，但需保留来源和报告期，不能覆盖官方披露。
4. **ETF/指数基金的每日或较高频申赎清单（PCF）**：若公开提供，应优先于季度持仓；主动公募基金通常不具备该信息。

- [天天基金：资产配置](https://fund.eastmoney.com/data/zcpzlist.aspx)

## 4. 低覆盖率基金的推荐模型

### 4.1 分层估值，而非猜测单只股票

```text
基金估算收益
= 已披露证券逐只加权收益
+ 未披露股票权重 × 股票/行业代理收益
+ 债券权重 × 债券指数收益
+ 现金权重 × 货币市场收益
+ 汇率影响（适用于外币资产）
```

实施顺序：

1. 从资产配置表读取股票、债券、现金、基金等大类权重；
2. 已披露证券按实际权重和实时行情计算；
3. 将未披露股票部分按行业、地区或业绩比较基准的权益部分映射到代理指数；
4. 债券、现金仅在资产配置表明确存在时纳入对应代理；
5. 明确标记哪些部分是“实际披露持仓”、哪些部分是“模型代理”。

不能因为业绩比较基准含有债券指数，就推断基金未披露部分一定持有同等比例的债券。业绩比较基准用于绩效比较，不等同于实际资产配置。

### 4.2 代理收益的滚动校准

可用过去 20～60 个已公布官方净值日拟合未披露部分的因子暴露：

```text
官方日收益 - 已披露持仓收益
≈ β1 × A股行业指数收益
+ β2 × 港股/美股指数收益
+ β3 × 债券指数收益
+ 常数项
```

约束与验证要求：

- 只使用当时已公开的数据，禁止使用未来报告期持仓或未来行情；
- 使用滚动窗口和样本外回测；
- 对 beta 加非负、权重和、正则化等约束，避免小样本过拟合；
- 输出模型覆盖率和历史误差，而不是声称识别了未披露个股。

## 5. 个案验证

### 5.1 022365：永赢科技智选混合发起C

2026Q2 前十大股票合计 61.88%。2026-08-07 官方净值从 5.2594 上升至 5.4068，实际收益为 +2.8026%；旧持仓法收益为 +1.4592%，少估 1.3434 个百分点。

该基金无已维护的跟踪指数映射。建议先获取其资产配置和行业配置，再为未披露股票部分设置科技权益代理；不要将前十大简单放大到 100%。

手工验证中，若将未披露 38.12% 使用官方比较基准的权益/科技代理，2026-08-03 至 2026-08-07 的平均绝对偏差由约 1.30% 降至约 0.78%。但 2026-08-03 与 2026-08-06 未改善，说明必须做滚动校准，不能仅固定套用比较基准。

该基金的官方业绩比较基准为“中国战略新兴产业成份指数收益率 × 70% + 恒生科技指数收益率（按估值汇率折算）× 10% + 中债-综合指数（全价）收益率 × 20%”。它可作为代理候选，但不等同于实际资产配置。

### 5.2 017436：华宝纳斯达克精选股票发起式(QDII)A

2026Q2 前十大股票权重合计 62.62%。该基金还存在 QDII 特有问题：

- 官方净值相对中国市场有披露滞后；
- 旧模型以较早官方净值为基准时，只应用了单日美股涨跌，没有从基准净值日累计至目标日；
- 基金以人民币计价，必须纳入 USD/CNY 汇率变动；
- 美股日线仅含交易日日期时，不能直接与中国本地的无时区估算时间比较；必须按海外市场实际收盘可用时点判断；
- 个别股票历史行情缺失时，应降低覆盖率，不应用其他股票补足。

离线回测（2026-07-31 至 2026-08-06 的 5 个已公布官方净值日）采用 2026Q2 持仓、从上一官方净值日累计的美股收益和 USD/CNY 中间价变化。旧方法平均绝对偏差约 2.19%，改进方法约 0.87%，改善约 60.4%。

该回测仍将未披露部分按 0 收益处理，因此不是最终模型；早期日期的实际可用行情覆盖率为 57.68%，2026-08-06 为 62.62%。

## 6. QDII 专项实现原则

1. 为行情记录保存市场时区、交易日和可用时间；
2. 仅使用估算时刻之前海外市场已收盘并可取得的行情；
3. 从 `base_nav_date` 到目标估算交易日按逐资产累计收益，而不是只取最新一日涨跌幅；
4. 外币资产按估值汇率换算；
5. 当官方净值、海外行情或汇率缺失时，返回明确原因并降低覆盖率，不以旧行情伪装为实时估值。

## 7. 验收指标

每次模型变更至少应产出：

- 各基金、各交易日的官方净值、估算净值、绝对偏差、偏差率；
- 真实披露覆盖率、实际行情覆盖率、模型代理比例；
- 按基金类型（普通权益、指数、ETF 联接、QDII）分组的 MAE 和改善率；
- 与旧模型的同区间、同一估算时点对比；
- 样本外回测结果。

只有在样本外 MAE 稳定下降且没有明显扩大极端误差时，才将新策略设为默认策略。
